# Simple XO PWA

Application minimale XO (tic-tac-toe) en HTML/CSS/JS, packagée comme PWA simple.

Pour lancer localement :

```bash
# Serveur simple (port 8000)
python3 -m http.server 8000

# ou avec npm (si installé)
npx serve .
```

Puis ouvrir http://localhost:8000

Fichiers créés:
- index.html
- styles.css
- app.js
- manifest.json
- sw.js

Icônes ajoutées dans le dossier `icons/` : `icon-192.svg`, `icon-512.svg`.
